## 一、三步快速上手 (Quickstart)

### 步骤 1：准备上游账号与登录态
网关底层融合两大上游算力，您可按需配置其中任一专线或全部配置：
* **Google 专线**：
  在终端中执行以下指令，浏览器将自动唤起 Google OAuth 授权：
  ```bash
  npm run account:login
  ```
  授权成功后，网关自动换取 Refresh Token，获取 Google Cloud Code PA 内部项目编号并持久化至 `data/google-accounts.json`。
* **Codex 专线**：
  若您已在本地安装并登录官方 Codex CLI（登录凭证位于 `~/.codex/auth.json`），网关**全自动即开即用**，无需任何额外配置，无需消耗商业 API Token。

### 步骤 2：一键启动后台静默守护服务
推荐使用原生 Windows 后台服务模式（开机静默启动、零黑框控制台窗口、崩溃自愈）：
```bash
npm run service:install
```
执行完毕后，终端打印 `🚀 Background Service Started Successfully`，此时即可**直接关闭该终端窗口**，服务将常驻系统后台。

### 步骤 3：访问 Web 控制台
在浏览器中打开：
> **Web 控制台地址**：[http://127.0.0.1:18763/](http://127.0.0.1:18763/)

主页实时呈现双专线连通性、本地凭据状态、当日吞吐统计与各视图快捷导航。

## 二、后台静默服务与日常运维 (Daemon Management)

网关内置了纯原生、零外部依赖的 Windows 后台服务套件，可直接通过 NPM 命令管理：

| 指令 | 说明 | 适用场景 |
| :--- | :--- | :--- |
| `npm run service:install` | **一键安装开机自启并启动** | 首次配置或开机自启动设置 |
| `npm run service:status` | **查看后台服务运行状态** | 查询 Master PID、内存、实时健康度、开机自启状态 |
| `npm run reload` | **零停机平滑热升级 (Hot Reload)** | 修改代码或配置后无感生效，**绝不中断正在进行的流式推理** |
| `npm run service:stop` | **停止后台服务** | 优雅终止 Cluster 进程树并清理 PID 锁文件 |
| `npm run service:restart` | **重启后台服务** | 停止后重新拉起后台服务 |
| `npm run service:uninstall` | **彻底卸载自启动** | 删除 Startup 目录自启脚本与任务计划，并停止服务 |

> [!TIP]
> **更新代码后如何平滑生效？**  
> 严禁直接杀进程强制重启！在任何终端中执行 `npm run reload` 即可。Master 进程将自动启动新 Worker，完成端口握手后平滑接管，老 Worker 自然排空正在进行的 SSE 推理长连接后退出，达成**零中断、零丢包、零端口冲突**。

## 三、主流 Agent 客户端接入实操 (Client Configuration)

网关对外提供两大标准协议：
* **Anthropic Messages 接口**：`http://127.0.0.1:18763`（或 `http://127.0.0.1:18763/v1/messages`）
* **OpenAI Chat Completions 接口**：`http://127.0.0.1:18763/v1`（或 `http://127.0.0.1:18763/v1/chat/completions`）
* **默认本地密钥 (API Key)**：`sk-gateway-local-token`（可在 `config.json` 中自定义）

---

### 1. Claude Code CLI (官方终端)

网关内置了**工具协议 7 阶段净化器**与**出站自愈器**，深度自愈 Claude Code v2.1.302+ 的 `EnterPlanMode` 占位报错、`Glob` 缺失 `pattern` 与 Gemini 3+ 签名丢失问题。

#### Windows PowerShell 环境
```powershell
$env:ANTHROPIC_BASE_URL = "http://127.0.0.1:18763"
$env:ANTHROPIC_API_KEY = "sk-gateway-local-token"

# 启动 Claude Code 并使用 Google 专线最强代码模型
claude --model claude-sonnet-4-6

# 或使用 Codex 专线免 Token 算力模型
claude --model gpt-6.1-sol
```

#### Windows CMD 环境
```cmd
set ANTHROPIC_BASE_URL=http://127.0.0.1:18763
set ANTHROPIC_API_KEY=sk-gateway-local-token
claude --model claude-sonnet-4-6
```

#### macOS / Linux / WSL (Bash/Zsh)
```bash
export ANTHROPIC_BASE_URL="http://127.0.0.1:18763"
export ANTHROPIC_API_KEY="sk-gateway-local-token"
claude --model claude-sonnet-4-6
```

### 6. Python / Node.js OpenAI SDK 脚本

#### Python
```python
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:18763/v1",
    api_key="sk-gateway-local-token"
)

response = client.chat.completions.create(
    model="claude-sonnet-4-6", # 或 "gpt-6.1-sol"
    messages=[
        {"role": "user", "content": "请用 Mermaid 写一个用户登录状态机"}
    ],
    stream=True
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="", flush=True)
```

#### Node.js
```javascript
import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: 'http://127.0.0.1:18763/v1',
  apiKey: 'sk-gateway-local-token'
});

const stream = await openai.chat.completions.create({
  model: 'gpt-6.1-sol',
  messages: [{ role: 'user', content: '写一个快速排序' }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || '');
}
```

## 四、模型选型与常用路由推荐 (Models Cheat Sheet)

网关全面取消前缀模糊推断，采用**确定性目录匹配**。请优先选用以下标准模型 ID：

| 模型 ID | 上游专线 | 特性定位与推荐场景 | 思考强度 (Reasoning Effort) 支持 |
| :--- | :---: | :--- | :---: |
| `claude-sonnet-4-6` | **Google** | **全场景最强代码生成**。复杂工程重构、跨文件架构设计首选 | `low`, `medium`, `high` (自动映射 PA 预算) |
| `gemini-3.8-flash-tiered`| **Google** | **极速流式交互**。高吞吐、低延迟，适合日常问答与轻量任务 | `low`, `medium`, `high` |
| `gemini-2.5-flash` | **Google** | 快速响应与通用补全 | `low`, `medium`, `high` |
| `gpt-6.1-sol` | **Codex** | **OpenAI Codex 前沿旗舰**。免 Token 计费，超强逻辑推演 | `low`, `medium`, `high` (自动探测保存) |
| `gpt-6-astra` | **Codex** | Codex 专线代码优化模型，高响应速率 | 支持探测档位 |
| `gpt-5.5` | **Codex** | 轻量快速代码生成 | 支持探测档位 |

> [!NOTE]
> 查看全量可用模型：可在 Web 控制台 `/models` 面板查看，或下发 `GET /v1/models`。已按对话、补全、生图、语音等多维分类展示。

## 五、Web 极客控制台导览 (Web Dashboard Guide)

控制台采用 Linear / Vercel 极客暗黑美学构建，内置 8 大功能板块：

1. **总览中心 (`/`)**：双专线实时生命线监测、上游连通性检测、今日调用吞吐量与健康横幅；
2. **模型管理 (`/models`)**：多维分类模型清单、差量刷新检测、单个/顺序批量模型连通性探测、Effort 档位配置保存；
3. **Google 账号池 (`/google-accounts`)**：查看多账号配额状态、一键 OAuth 新增账号、单号启用/停用与优先级设置；
4. **Codex 订阅与配额 (`/codex`)**：本地 `auth.json` 状态探测、上游真实连通性测试、Weekly 额度重置窗口刷新；
5. **全链路请求日志 (`/requests`)**：以 Request ID 为线索，追踪包含入站、出站、上游响应、SSE 分块在内的全量上下文；
6. **用量与消耗趋势 (`/usage`)**：每日请求分布、上游 Token 消耗统计、成功率分析；
7. **实时推理测试台 (`/playground`)**：在网页端直接选择任意模型发起流式对话测试，验证模型连通性与吞吐；
8. **客户端接入指南 (`/connect`)**：提供各大客户端的一键复制环境变量与配置模板。

## 六、常见问题排错 (FAQ & Troubleshooting)

### Q1：关掉敲命令的黑框窗口后，服务会停吗？
* **不会**。只要您是通过 `npm run service:install` 或 `npm run service:start` 启动的，网关是以独立的后台守护模式运行的，可以直接关闭终端；
* 每次开机或系统重新登录，也会通过 Startup 目录自动在后台静默运行。

### Q2：更新了代码或者修改了配置文件，需要重启服务吗？
* 不需要重启！直接在任意终端运行：
  ```bash
  npm run reload
  ```
  Master 进程会自动加载新代码并热切换，正在生成文本的会话不受任何中断影响。

### Q3：Claude Code 提示 `EnterPlanMode` 或 `Glob failed: pattern is missing` 报错怎么办？
* 网关已内置 [tool-healer.ts](../../src/providers/google/tool-healer.ts)，自动将 `EnterPlanMode` 的非法占位参数剥除为 `{}`，并对缺失的 `pattern` 进行通配符自愈提取。确保您使用的是最新网关服务（若刚拉取代码，运行 `npm run reload` 即可）。

### Q4：调用报 401 Unauthorized？
* 检查您的客户端请求 Headers：网关默认 API Key 为 `sk-gateway-local-token`，可配置为 `Authorization: Bearer sk-gateway-local-token` 或 `x-api-key: sk-gateway-local-token`。

### Q5：Google 上游偶发 429 Resource exhausted？
* 属于 Google 云端并发或配额限制。网关会在同一账号下自动以 250ms/500ms 退避重试 3 次；若该账号配额耗尽，可在 `/google-accounts` 切换其他启用账号。
